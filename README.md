# Markdown Notes for Ableton Live

**Current Version: v2.0**

Markdown Notes is a Max for Live device for writing, organizing, and managing production notes directly inside Ableton Live.

It combines a Markdown editor with a real-time preview, making it useful for arrangement planning, track notes, mixing reminders, checklists, sound design notes, and session documentation.

The device provides a compact editor in Ableton Live's Device View and a separate resizable editor window for more comfortable editing.

## Features

### Markdown Editor

- Real-time Markdown preview
- Edit / Split / Preview modes
- Separate resizable editor window
- Synchronized scrolling between editor and preview
- Line numbers
- Word wrap
- Adjustable editor font size
- Markdown syntax highlighting
- Table of Contents (TOC) navigation
- Open, Save, and Save As
- Single `.amxd` file
- No external HTML or JavaScript files required

### Search and Editing

- Search with next / previous navigation
- Search and replace
- Replace all
- Case-sensitive search
- Regular expression search
- Regular expression replacement
- Capture-group replacement using `$1`, `$2`, etc.
- `Ctrl + D` multi-selection
- `Ctrl + Shift + L` select all matching words
- Multi-editing of repeated text
- Japanese IME compatible multi-editing

### Markdown Support

- Headings
- Bold and italic text
- Strikethrough
- Horizontal rules
- Ordered and unordered lists
- Checklists
- Blockquotes
- Inline code
- Fenced code blocks
- Links
- Tables

### Interface

- Compact interface for Ableton Live's Device View
- Separate editor window for detailed editing
- Edit / Split / Preview switching
- Line number toggle
- Word wrap toggle
- Adjustable zoom
- Table of Contents navigation
- Keyboard shortcut controls
- Editor status information

## Usage

Place `Markdown_Notes_v2.0.amxd` on an Audio Track or MIDI Track in Ableton Live.

The device is built as an Audio Effect with transparent audio pass-through, so it does not affect the sound.

You can use Markdown Notes for:

- Song arrangement planning
- Track-by-track production notes
- Mixing and mastering reminders
- Sound design documentation
- Recording notes
- To-do lists and checklists
- Session documentation
- Song structure planning
- Production ideas and references

### Editing Modes

**Edit** — Displays the Markdown source editor.

**Split** — Displays the editor and rendered preview side by side.

**Preview** — Displays the rendered Markdown document.

Use **OPEN EDITOR** to open the separate editor window for a larger workspace.

### Default Markdown Template

Version 2.0 includes a compact song arrangement template demonstrating common Markdown syntax.

The template includes project information, arrangement sections, tables, checklists, notes, links, and code blocks.

You can replace or edit the template to create your own production notes.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + F` | Search |
| `Ctrl + H` | Search and Replace |
| `Ctrl + D` | Add the next matching word to multi-selection |
| `Ctrl + Shift + L` | Select all matching words |
| `Enter` | Next search result |
| `Shift + Enter` | Previous search result |
| `Esc` | Cancel multi-selection |

Keyboard shortcuts may depend on editor focus and the operating system.

## Installation

1. Download the latest `Markdown_Notes_v2.0.amxd` file.
2. Drag it into Ableton Live.
3. Optionally save it to your Ableton User Library.

No additional HTML or JavaScript files are required.
